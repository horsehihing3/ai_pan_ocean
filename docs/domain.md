## 도메인 용어

| 용어 | 정의 | 혼동 주의 |
|------|------|------|
| 사업장 출입신청 | 협력업체가 특정 선박/사업장 작업 전 제출하는 허가 신청 | ≠ 안전보건평가 |
| 안전보건평가 | 계약부서가 협력업체 전반을 주기적으로 평가하는 절차 | ≠ 반기평가 |
| 반기평가 | 협력업체가 자체적으로 제출하는 반기별 실적 평가 | ≠ 안전보건평가 |
| 정보수집 | 카카오톡으로 현장 서류(일일안전교육일지·작업계획서 등) 자동 수집 | 카카오 비즈메시지 API 연동 |
| 요주의 업체 | 개선요청 미이행, 재해율 높은 업체 (기준값 미확정) | 자동 플래그 예정 |
| 안전보건실적 | 부서별 예산·사고 등 실적 포털 입력·취합 | 기존 이메일 취합 대체 |
| 승선대표자 | 카카오톡 정보수집 서류 제출 담당자 | 협력업체 안전담당자와 동일인일 수 있음 |

## 핵심 업무 흐름

### ① 가입·승인
```
협력업체 가입신청 (업종·계약팀 선택)
→ 안전경영팀에 이메일 알림
→ 2일 내 미승인 시 리마인드 이메일 자동 발송
→ 승인: 협력업체에 완료 이메일
→ 반려: 협력업체에 사유 포함 이메일
```

### ② 사업장 출입신청
```
협력업체 신청서 작성 (선박명·지역·작업일정·인원명단)
→ 위험성평가·안전보건서약서·작업계획서 첨부
→ 관리자 서류 검토 (검토중 / 개선요청 / 완료)
→ 개선요청 시: 사유 입력 → 협력업체 이메일 자동 발송
→ 검토완료 후 수정 불가
```

### ③ 카카오 비즈메시지 정보수집
```
관리자 → 승선대표자 카카오톡으로 서류 제출 요청
→ 대표자 서류 제출 (일일안전교육일지·작업계획서·서명본)
→ 웹훅 수신 → 스캔본 시스템 자동 등록
→ 기존 출입신청 기록과 사업자번호 기준 자동 매칭
```

### ④ 협력업체 안전보건평가
```
계약부서 평가 수행 (적격 / 부적격)
→ 증빙서류 첨부
→ 관리자 검토 (검토중 / 개선요청 / 완료)
→ 개선요청 시: 사유 → 이메일 자동 발송
→ 평가 항목은 관리자가 언제든 수정 가능
```

### ⑤ 반기평가
```
협력업체 자체 반기평가 작성·제출
→ 근로자 의견조회 포함
→ 관리자 집계·모니터링
→ 요주의 업체 자동 플래그 (기준 향후 설정)
```

### ⑥ 안전보건실적
```
(기존) 이메일 개별 연락 → 개별 취합
(변경) 각 부서가 포털에서 직접 실적 입력
→ 관리자 종합 조회 → 엑셀 다운로드
※ 예산내역은 FCM/VBP 연동 예정
```

### ⑦ 산업재해 LIST
```
협력업체 또는 계약부서가 재해발생 신고
→ 사업장산업재해율조사표·원인및재발방지대책 파일 업로드
→ 사업자번호 기준 자동 매칭·기록 관리
```

### ⑧ 보건파트
```
병원자료 업로드 → LIST 자동 등록
→ 이름 클릭 시 3개년 수치 팝업
→ 이전 상담내역 조회 가능
```
